# MLOps Projects

End-to-end ML pipelines orchestrated with Apache Airflow.

## airflow-pipelines
- `dags/` - Airflow DAGs (ETL, ML, NLP, deep learning)
- `serve/` - model serving apps
- `deploy/` - deployment files
- `models/` - trained models

## Datasets
Wine, IMDB reviews, MNIST (downloaded by the DAGs, not stored in the repo).
